# Plugin.Avalonia.MVVMExpress.Templates

`dotnet new` templates for **Plugin.Avalonia.MVVMExpress**.

```bash
dotnet new install Plugin.Avalonia.MVVMExpress.Templates
dotnet new avalonia-mvvmexpress -n MyApp
dotnet new avalonia-mvvmexpress-page -n Catalog --namespace MyApp
```

This is not Plugin.Maui.MVVMExpress.Templates. There is no Shell — use a `Frame` named `NavigationHost`.
