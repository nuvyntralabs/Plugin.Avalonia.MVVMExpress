# Avalonia MVVMExpress for VS Code

Installs `Plugin.Avalonia.MVVMExpress.Templates` and runs `dotnet new avalonia-mvvmexpress` / `avalonia-mvvmexpress-page`.

Commands:

- **Avalonia MVVMExpress: Create New App**
- **Avalonia MVVMExpress: Add Page**

This is not the MAUI MVVMExpress extension. Marketplace upload is manual from the `ide-extensions` workflow artifact.
